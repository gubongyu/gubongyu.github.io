움직임은 웹사이트의 분위기를 만듭니다. 버튼을 눌렀을 때의 반응, 오브젝트의 기울기, 부드러운 화면 전환은 공간을 살아 있는 것처럼 느끼게 합니다.

> 이 글은 예제 콘텐츠입니다. 실제 개발 기록으로 교체할 수 있습니다.

## 탐색하는 화면과 읽는 화면

홈에서는 공간의 개성을 보여줍니다. 글 상세에서는 문장 사이의 흐름이 가장 중요합니다. 그래서 3D 장면은 홈에 두고, 본문 주변의 움직임은 최소화했습니다.

## 움직임을 선택할 수 있게

시스템의 동작 줄이기 설정을 존중하고, 사이트에서도 움직임을 끌 수 있어야 합니다. 화면이 움직이지 않아도 모든 정보와 링크에 접근할 수 있어야 합니다.

```css
@media (prefers-reduced-motion: reduce) {
  .card {
    transform: none;
  }
}
```

## 먼저 보이는 내용

장식이 로딩되는 동안에도 제목과 소개, 링크는 먼저 표시합니다. 이미지와 캔버스가 들어갈 자리를 예약하면 뒤늦게 화면이 밀리는 일도 줄일 수 있습니다.

좋은 인터랙션은 콘텐츠에 들어가는 문을 열어 줍니다. 읽기 시작한 뒤에는 자연스럽게 뒤로 물러납니다.
